#

An intelligent AI-powered application designed to help students organize academic life. It uses the Google Gemini API to analyze user events and tasks, generating optimized weekly schedules and actionable study plans.

## Key Features

*   **AI Plan Generation:** Creates personalized schedules using Google Gemini based on events and priorities.
*   **Interactive Schedule:** Dynamic visualization showing planned tasks and events.
*   **Event & Task Management:** Input and manage fixed events and flexible priority/to-do lists.
*   **AI Chat Assistant:** Conversational AI aware of the user's schedule and plan.
*   **Local Authentication & Data:** User signup/login and data persistence using local JSON files.
*   **Gamification:** Leveling system for task completion.

## Technology Stack

*   **Frontend:** React
*   **Backend:** Node.js, Express.js
*   **AI:** Google Gemini API
*   **Database:** Local File System (JSON)

⚠️ This version uses a **local file system for data storage and authentication**. It is **NOT suitable for production deployment.**
